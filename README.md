## Getting Started

/to run the application
~~~shell
flutter run
~~~


// To update ios pods
~~~shell
    cd ios
    pod init
    pod update
    pod install
~~~
//To clean the pub cache
~~~shell
flutter clean
flutter pub cache clean
flutter pub get
~~~
//To repair the pub cache
~~~shell
flutter clean
flutter pub cache repair
flutter pub get
~~~
