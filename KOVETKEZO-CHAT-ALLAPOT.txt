VESZPREMI TAXI - SOFORAPP ALLAPOT (2026-07-24)

MI MUKODIK
- A Flutter soforapp Android debug APK-ja helyben es Codemagicben is lefordul.
- Az elozo indulaskori osszeomlas javitva, az alkalmazas elindul.
- API alapcim: https://api.veszpremitaxi.hu/api
- Codemagic: Flutter 3.41.9, Android APK, Debug, project path '.', GOOGLE_MAPS_API_KEY secret.

MOSTANI APP-VALTOZTATAS: 1.0.3+9
- Az elso hasznalhato kepernyo mar csak: Felhasznalonev/e-mail + Jelszo + Belepes.
- Nincs lathato telefonszamos belepes, OTP, Google/Apple belepes vagy sofori regisztracio.
- A belepes nem hasznal Firebase Authot, kozvetlenul a /driver/login/password API-t hivja.
- Sikeres token utan egybol a sofori fooldal nyilik meg.
- Kijelentkezes vagy ervenytelen token utan ugyanez az uj belepesi oldal jon vissza.
- A regi regisztracios forrasfajlok biztonsagi okbol meg a projektben vannak, de az appbol nem erhetoek el. Mukodo belepes utan lehet oket fizikailag is takaritani.

KOVETKEZO KONKRET FELADAT
- Backend: DriverAuthController@loginWithPassword fogadjon egyetlen 'identifier' mezot, es keressen a soforok kozott nev VAGY e-mail alapjan.
- A backend maradjon kompatibilis az 'email' mezovel is.
- Sikeres belepesnel ugyanazt a token + driver JSON formatumot adja, amit a jelenlegi appmodell var.
- Ezutan APK teszt: belepes -> online/offline -> fuvar erkezik -> elfogadas.
